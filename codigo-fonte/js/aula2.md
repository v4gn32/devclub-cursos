## Resumo da Aula 2 - JavaScript

Nesta aula, aprendemos sobre a versatilidade do JavaScript e os motivos para utilizá-lo no desenvolvimento de aplicações. JavaScript é uma linguagem poderosa, capaz de ser usada tanto no frontend (sites e interfaces) quanto no backend (servidores e APIs).

### Por que usar JavaScript?
- **Versatilidade:** Permite criar sites, sistemas web, aplicativos mobile e até programas de computador.
- **Comunidade ativa:** Grande quantidade de bibliotecas, frameworks e suporte.
- **Multiplataforma:** Funciona em diferentes ambientes, como navegadores, servidores (Node.js) e dispositivos móveis.

### Exemplos de uso
- **Backend:** Node.js para criar servidores e APIs.
- **Aplicativos Mobile:** React Native para apps Android e iOS.
- **Programas Desktop:** Electron para criar aplicativos de computador com tecnologias web.

JavaScript é uma ótima escolha para quem busca flexibilidade e produtividade no desenvolvimento de software.
