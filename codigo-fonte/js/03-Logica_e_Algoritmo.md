# Lógica de Programação

## O que é?

Lógica de programação é a forma lógica de se comunicar com o computador. Os computadores não entendem linguagem humana diretamente, por isso precisamos aprender como nos comunicar com eles de maneira estruturada e lógica.

- **Lógica de programação** é o conjunto de regras e técnicas para desenvolver instruções que o computador possa entender e executar.
- Aprender lógica de programação é aprender como o computador "pensa" e como podemos nos comunicar com ele de forma eficiente.

## Por que aprender lógica de programação?

- Facilita o entendimento de qualquer linguagem de programação.
- Ajuda a resolver problemas de forma estruturada.
- Permite criar soluções eficientes e reutilizáveis.

---

## Algoritmo

### O que é um algoritmo?

Um **algoritmo** é uma sequência lógica e finita de passos para resolver um problema ou executar uma tarefa.

- Exemplo: Receita de bolo.
- É uma descrição detalhada, passo a passo, de como realizar uma atividade.

### Características de um algoritmo

- **Clareza:** Cada passo deve ser claro e objetivo.
- **Finitude:** Deve ter um número limitado de passos.
- **Definição:** Não pode haver ambiguidade nas instruções.
- **Entrada e saída:** Deve receber dados de entrada e produzir uma saída.

---

## Exemplo prático: Algoritmo para fazer café

```markdown
1. Verifique se a cafeteira está ligada na tomada.
    - Se não estiver, ligue-a na tomada.
2. Verifique se o compartimento de água está cheio.
    - Se não estiver, coloque água.
3. Verifique se o compartimento já tem uma cápsula.
    - Se não tiver, coloque uma cápsula.
4. Aperte o botão para iniciar o preparo do café.
5. Aguarde até o café ficar pronto.
6. Sirva o café na xícara.
```

---

## Representação de algoritmos

- **Texto:** Como o exemplo acima.
- **Fluxograma:** Diagrama visual que representa o fluxo de execução.
- **Pseudocódigo:** Descrição estruturada, próxima de uma linguagem de programação, mas sem sintaxe rígida.

---

## Dicas para criar bons algoritmos

- Divida o problema em pequenas etapas.
- Seja detalhista e evite ambiguidades.
- Teste cada etapa para garantir que está correta.
- Revise e otimize o algoritmo quando possível.

## Próximos passos

- Aprofunde-se em estruturas de controle (condicionais, repetições) e estruturas de dados (variáveis, listas).
