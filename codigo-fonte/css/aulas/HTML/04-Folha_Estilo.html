Folha de Estilo em Cascata (CSS)

Folha de Estilo em Cascata (CSS) é uma linguagem utilizada para definir a aparência e o layout das páginas HTML. Com o CSS, é possível controlar cores, fontes, espaçamentos, posicionamento de elementos e muito mais, separando o conteúdo da apresentação. O termo "cascata" refere-se à forma como as regras são aplicadas, permitindo herança e prioridade entre diferentes estilos. Ele sempre vai manter o que vc aplicou por ultimo.
