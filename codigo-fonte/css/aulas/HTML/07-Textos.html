Texto no CSS

O CSS permite estilizar textos de diversas formas, tornando o conteúdo mais atraente e legível. Veja abaixo os principais recursos:

Cor do Texto

color: #ffffff;

Define a cor do texto.

Fonte

font-family: Arial, sans-serif;

Escolhe a família de fontes utilizada.

Tamanho da Fonte

font-size: 18px;

Altera o tamanho do texto.

Estilo da Fonte

font-style: italic;

Deixa o texto em itálico.

Peso da Fonte

font-weight: bold;

Deixa o texto em negrito.

Alinhamento do Texto

text-align: center;

Centraliza o texto.

Transformação do Texto

text-transform: uppercase;

Transforma o texto em maiúsculas.

Espaçamento entre Letras

letter-spacing: 2px;

Define o espaçamento entre caracteres.

Espaçamento entre Linhas

line-height: 1.5;

Define o espaçamento entre linhas de texto.

Espaçamento entre palavras

word-spacing: 10px;

Define o espaçamento entre palavras de texto.

Sombra no Texto

text-shadow: 2px 2px 4px #888;

Adiciona sombra ao texto.

Decoração do Texto

text-decoration: underline;

Sublinha o texto.

Exemplo de uso


    p {
        color: #444;
        font-size: 16px;
        font-family: Verdana, sans-serif;
        text-align: justify;
        line-height: 1.6;
    }

Essas propriedades podem ser combinadas para criar estilos personalizados para qualquer texto em sua página.
