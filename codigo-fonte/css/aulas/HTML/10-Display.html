O que é a propriedade display no CSS?

A propriedade display define como um elemento HTML será exibido na página. Ela controla o comportamento de layout dos elementos, como blocos, linhas ou outros modelos de layout.

Principais valores de display

  • block: O elemento ocupa toda a largura disponível, começando em uma nova linha. Exemplos: <div>, <h1>, <p>.
  • inline: O elemento ocupa apenas o espaço necessário e não inicia uma nova linha. Exemplos: <span>, <a>.
  • inline-block: Mistura características dos dois anteriores: fica na mesma linha, mas aceita largura e altura.
  • none: O elemento não é exibido na página.
  • flex: Ativa o modelo de layout flexível (Flexbox).
  • grid: Ativa o modelo de layout em grade (Grid).

Exemplos de uso

1. display: block

<div style="display: block; background: #e0e0e0;">Elemento block</div>
Elemento Block

2. display: inline

<span style="display: inline; background: #c0ffc0;">Elemento inline</span>
Elemento inline

3. display: inline-block

<span style="display: inline-block; width: 120px; background: #c0c0ff;">Inline-block</span>
Elemento inline-block

4. display: none

<div style="display: none;">Este texto não aparece</div>
Elemento none

5. display: flex

<div style="display: flex;">
        <div style="background: #ffd700; margin: 4px;">Item 1</div>
        <div style="background: #adff2f; margin: 4px;">Item 2</div>
      </div>
Elemento Flex
Elemento 2 Flex

Dicas

  • Use display: none para esconder elementos sem removê-los do HTML.
  • display: flex e display: grid são ótimos para layouts modernos e responsivos.
  • O valor padrão de display depende da tag HTML.
