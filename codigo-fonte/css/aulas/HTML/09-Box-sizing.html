Tutorial: Entendendo o box-sizing no CSS

O que é box-sizing?

O box-sizing é uma propriedade do CSS que define como a largura e a altura de um elemento são calculadas: se incluem ou não o padding e a borda.

Valores possíveis

  • content-box (padrão): Apenas o conteúdo é considerado na largura e altura. O padding e a borda são adicionados fora dessas dimensões.
  • border-box: O padding e a borda são incluídos dentro da largura e altura definidas.

Exemplo prático

content-box
Largura: 200px
Padding: 20px
Borda: 5px
border-box
Largura: 200px
Padding: 20px
Borda: 5px

No exemplo acima, ambos os blocos têm width: 200px, padding: 20px e border: 5px.
content-box: a largura total será 200 + 20*2 + 5*2 = 250px.
border-box: a largura total permanece 200px, pois o padding e a borda já estão inclusos.

Como usar no seu projeto

/* Recomenda-se usar border-box em todos os elementos */
    * {
        box-sizing: border-box;
    }

Isso facilita o controle do layout e evita problemas de dimensionamento.

Resumo

  • box-sizing controla como o tamanho dos elementos é calculado.
  • border-box é mais previsível e recomendado para a maioria dos projetos.
  • Use * { box-sizing: border-box; } para aplicar globalmente.
